Phase Mapping (Less-Than-7-Day Install)

Phase 1 - Days 1-3 (Core Funnel Install)

Goal: VSL bridge live, brand colours locked, homepage rewritten to route into scorecard.

  • Day 1: Brand colour lock on AG1 sample assets to match chrisharder.me palette. Homepage VSL script lock (Chris + Lori). Scorecard question set lock.
  • Day 2: Homepage VSL shoot day (Chris + Lori, 1 day, 3 takes: homepage 6-10 min, EEM apply 4-6 min, MCM apply 4-6 min). Sample landing page deployed at https://andrei170.github.io/chris-harder-landing/ for review.
  • Day 3: VSLs cut, embedded on homepage + EEM apply page + MCM apply page. Money Multiplier Score deployed live on Typeform (uTtFirS4 working form ID). Scorecard email-capture tagged to ESP.

Phase 2 - Days 4-7 (Scorecard + Nurture + Sprint Page)

Goal: Segmented welcome flow live, sprint sales page deployed, MCM warm-list holding pattern ready for next dark window.

  • Day 4: Lane A / Lane B / Lane C welcome flows built in ConvertKit (or current ESP). 14-day cadence per lane. Auto-routing from scorecard output + blueprint download tag + podcast-subscribe tag.
  • Day 5: Sprint sales page deployed (separate landing, scorecard pre-app gate, capped 50, $497-$997 tier ladder).
  • Day 6: Bio-link router updated across IG / YouTube / LinkedIn / X to point at the scorecard as primary, with secondary links preserved.
  • Day 7: Full QA pass on the funnel (scorecard scoring logic, lane routing, ESP tags firing, VSL embeds responsive, sprint checkout firing). Handoff doc delivered.

Phase 3 - Post-Install Ongoing (Content Compound)

Goal: The podcast feeds the funnel; the funnel feeds the podcast.

  • Photoshoot / B-roll banking for VSL recuts and ad creative library (Chris + Lori, same shoot day if possible)
  • Content cadence: one episode-companion email per week into the segmented flow, tying the latest Chris Harder Show episode to whichever lane it best serves
  • Quarterly sprint cycle launches during MCM-closed windows
  • Cohort grad receipts captured on MCM wrap calls and EEM in-person events, swapped into the wall on the sales pages

Phase 4 - Post-Install Ongoing (Paid Traffic Layer)

Goal: The scorecard becomes the paid-traffic landing surface.

  • Pixel + GA4 + retargeting tags installed and firing across hub, landing, scorecard, sprint page, and apply pages
  • Top-performing organic clips from The Chris Harder Show boosted on Meta + YT shorts to the scorecard
  • Retargeting campaigns for landing-page abandons + scorecard quiz starts that did not complete
  • Cold campaigns to lookalike audiences of MCM + EEM applicants from sprint cycle 2 forward
  • Lead flow target: scaling toward a predictable scorecard completion rate that fills MCM cohorts via paid in parallel with organic

Integration Points

  • Scorecard to ESP: Typeform webhook to ConvertKit (or equivalent). On submit: tag = scored, custom field = score_band (A / B / C / D), auto-routes into the relevant welcome flow.
  • Scorecard to CRM: Same webhook fires a second event to Chris's CRM. New row created with score, band, primary bottleneck, contact info. Tagged for sales team review.
  • VSL to scorecard: Homepage VSL ends with a single call to take the Money Multiplier Score, button below the player. EEM apply-page VSL ends with the apply form below. MCM apply-page VSL ends with the apply form below.
  • Lane to apply page: Each lane's final email auto-routes the lane-correct apply page (Lane B = MCM apply, Lane C = EEM apply). Lane A finishes on a course-purchase ask. Score 90+ skips lanes and routes direct to 1-on-1 apply.
  • Sprint to MCM: Sprint grads get a fast-track invite to the next MCM cohort. Sprint application uses the same scorecard, so sprint applicants are already pre-scored when MCM opens.

Risk + Mitigation

Risk Likelihood Mitigation
Chris and Lori cannot shoot the VSL in the install week Medium Sample homepage VSL on Day 1 uses a podcast-clip placeholder so the funnel routes correctly while the custom shoot is scheduled. Custom VSL embeds swap in on shoot completion.
Scorecard length depresses completion rate Low-Medium Twelve questions is the upper bound. If completion rate drops below 60% in first 30 days, trim to 8 questions and re-test.
ESP migration if current tool does not support tag-based lane segmentation Low If Mailchimp is the current ESP, migration to ConvertKit happens in parallel during Phase 2. Adds 2-3 days to the install.
Sprint cycle 1 does not fill the cap Medium Cap is a soft cap. Sprint 1 is a calibration cycle. Pricing and messaging tune for sprint 2.
Application-page VSL pulls EEM close rate down (over-qualified applicants self-select out) Low Net effect on revenue is positive even if raw application count drops. The scorecard does the heavy filter; the VSL adds context.
Brand-voice drift on AG1-produced copy Low Copy strategy doc locks voice register; banned phrase list runs on every draft; Chris reviews homepage VSL script + EEM apply-page VSL script in Phase 1.
Sprint launches without the segmented welcome flow ready Medium Phase 2 sequencing pins sprint sales page deploy after welcome flow deploy. Sprint launch waits on Lane B + Lane C readiness.

  5. Confirm EEM and MCM apply-page edit access (does Chris's team or AG1 push the embed to mastermindharder.com / chrisharder.me/mentor, what is the deploy path).
  6. Confirm Frello brand reference policy (acknowledge on hub footer, do not foreground anywhere; confirm Chris is comfortable with the level used).

What This Blueprint Does Not Include

  • A new mastermind tier above EEM (out of scope; the wedge is infrastructure on the existing ladder, not new offer architecture)
  • A redesign of mastermindharder.com or chrisharder.me beyond VSL embeds and the scorecard CTA additions (the existing sites stay; the install adds layers, does not replace surfaces)
  • A change to the Frello brand or surfaces (Frello is a separate company, separate funnel, out of scope)
  • A change to the podcast cadence, episode structure, or guest mix (the podcast is the relationship engine, the install respects it)
  • A change to Chris's pricing on any existing program (pricing is locked by Chris; AG1 builds infrastructure around the current price points)

The install is conversion-infrastructure on top of a mature, working coaching ladder. It does not touch the offers, the brand, the podcast, or Frello.
